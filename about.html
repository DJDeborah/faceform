METHOD & PROVENANCE

从人脸到骨骼，哪些是观察，哪些是估计。

这里生成什么

照片输入通过 MediaPipe 检测稳定地标，用正则化的 SCULPTOR 形状参数拟合。3D 输入通过初始化点云配准拟合共享形状模型。完整估计头骨与脸部面皮来自同一组形状参数，再共同校准到目标面皮宽高。面皮只包含额头、面颊、鼻部与下巴，排除耳朵、后脑、颈部与肩膀。

图像和模型文件在访客浏览器内处理，无需登录，也不上传到服务器。浏览器会从原作者公开 GitHub 下载 SCULPTOR 模型；地标检测模型和运行库已随网站打包。首次准备约 80 MB 数据，之后缓存于浏览器。网站不需要站点所有者电脑运行。

统计骨骼的边界

单张照片看不到颅骨与头部深度。未观察到的骨骼、牙齿、后脑形状来自学习先验。脸部相似不代表隐藏骨骼准确；这里的 STL 用于造型与研究，不是个人 CT 的重建。3D 模型默认需要接近正面、Y 轴朝上和中性表情。较大姿态、遮挡、头发和极端表情会影响拟合。

“Morpheus 1:1”需要什么

Morpheus 的官方说明给出约 4 mm 的面皮参考厚度，以及约 2 mm 的眼周厚度。真实贴合还必须匹配官方 CAD 的内表面、外缘、眼口开口与驱动连接点，不能只设置相同宽高。当前提供的宽高校准是外形尺寸参考，未证明与机械结构 1:1 安装兼容。通用面皮壳采用均匀厚度；尚未实现眼周独立减薄、连接点与预应变设计。机械校准状态会写进生成报告。

STL 以毫米为约定单位。封闭性和非流形边检查通过后才开放导出；局部自交、最小壁厚、切片支撑、硅胶收缩和真实安装仍需进一步验证。

人脸阴阳模

先生成人脸面皮，再点击“生成浇注模具”。阴模形成光滑的外侧五官，阳模决定内表面。模具包含光滑分模过渡、三个非对称定位结构、下巴进料槽和额头排气槽，使用外夹具合模。计算采用正面开模包络，局部倒扣会简化；采样精度、平滑偏差、毫米尺寸及合模坐标变换随模具报告导出。生成结果尚需打印、表面处理与试浇。

已从官方 CAD 核对：原始 Morpheus 面皮外包围尺寸约 175.43 × 273.42 × 137.21 mm，原内表面并非统一 4 mm 偏置。这些尺寸属于官方原型，不能直接作为任意人脸的等比缩放或安装保证。

代码、模型与许可

FaceForm 公开源码仓库

  • SCULPTOR: Skeleton-Consistent Face Creation Using a Learned Parametric Generator，Qiu et al., SIGGRAPH Asia 2022。公开参数文件原始 Git blob：081e696dcc0d4e3e64fe723ed5f7ffabe0762c26。
  • generalized_face_model 研究复现仓库。本网站实现的是 SCULPTOR 的中性形状拟合与网格导出，不包含 Disney 论文完整的物理仿真训练和动画系统。
  • Morpheus 官方机械设计与硅胶面皮说明。
  • Google MediaPipe Face Landmarker。
  • Three.js 0.170.0 MIT 许可，用于预览与文件读取。

网站代码为独立实现，适用 MIT 许可。上游模型和素材仍适用原作者条款；网站不把 SCULPTOR 模型重新授权为 MIT，也不重新托管其原始权重。完整 LUCY 数据集没有被使用或再发布。模型由浏览器直接读取原作者 GitHub，安全数据读取器只提取数值数组，不执行 pickle 中的代码。

公开部署

项目是静态网页，可通过 GitHub Pages 公开部署。访问者无需账号，计算在浏览器执行；GitHub Pages 不需要 Python 服务或任何 API 密钥。
